# Codex 已在前台时点「前往会话」弹出关不掉的透明窗

**日期**：2026-09-20
**状态**：已修代码，待用户重载 sidecar 真机验证

## 症状

Codex 桌面 App（进程名 `ChatGPT.exe`）已经在前台时，点 agent-notify 卡片「前往会话」，Windows 上会出现一块透明、关不掉的窗口。退出 Codex App 后透明窗才一起消失。

## 复现

1. 打开 Codex 桌面 App，保持前台。
2. 等一张 Codex 会话 toast。
3. 点「前往会话」。
4. 出现透明覆盖层；任务栏/Alt+F4 关不掉，随 Codex 进程消失。

合成 harness（不碰真 Codex）：

```text
powershell.exe -NoProfile -NonInteractive -File tools/plugin-demo/agent-notify/runtime/focus-windows.repro.ps1
```

旧过滤器：`EXIT=1`，`afterOverlayVisible=true`。
新过滤器：`EXIT=0`，不选中 overlay。

## 根因

`focus-windows.mjs` 旧规则只认「有标题 + 无 owner」，并对**全部**候选执行 `ShowWindow(SW_SHOW)` + `SW_RESTORE`。

Codex 在前台时仍有隐藏顶层窗：

- `CodexComputerUseSwiftOverlay`：全屏、有标题、无 owner、`WS_EX_TRANSPARENT | TOOLWINDOW | NOACTIVATE`
- 隐藏的 `Chrome_WidgetWin_1` ghost（TOOLWINDOW + TOPMOST）

`SW_SHOW` 把 overlay 做成可见透明玻璃。它没有常规关闭按钮，生命周期跟 Codex 进程绑定。

## 修复

候选必须已经可见或已最小化；拒绝透明/TOOLWINDOW/NOACTIVATE overlay 和 `*Overlay*` 类名。Restore 只对最小化窗 `SW_RESTORE`，不再对隐藏窗 `SW_SHOW`。App 名单补上 `ChatGPT.exe`。

# dsh-chat 二轮：小窗可读性 + 设置页真正可编辑

日期：2026-10-03　插件：`tools/plugin-demo/dsh-chat/`　起因：用户反馈「好长的横向滚动条 / 设置完全没办法调整 / 可读性差」

## 用户看到的三件事，根因分别是

| 现象 | 根因 | 修法 |
|---|---|---|
| 消息区一条**长横线滚动条** | 只写了 `overflow-y: auto`。CSS 规定一轴非 visible 时另一轴 auto，于是长路径/长 JSON 顶出横向滚动 | 滚动容器显式 `overflow-x: hidden` + `overflow-wrap: anywhere`；工具参数用 `direction: rtl` 省略号保留尾部文件名 |
| 设置**完全没办法调整** | `NInput` 只给 `value` 不接 `onUpdate:value` → Naive 视为受控，打字不落 | 全部 `onUpdate:value` 写本地表单 + 500ms debounce 落 `plugin.config`；数值先存字符串、失焦再钳制 |
| 可读性差：满屏 `edit {...}`、底部三行模型名 | 连续 tool item 逐条铺开；状态行没截断 | 连续工具合成 `▸ N 个工具调用（x 个失败）` 折叠组；状态行 nowrap + ellipsis；会话选择固定 8.5rem |
| 窗口显示不完全（上一轮） | 卡片写死 24rem 超出宿主 22.5rem 卡槽 + 没传 `toastStyle:'standalone'` | `width:100% + border-box` + standalone（见上一个 devlog） |

## 顺手补的防线

- `plugin-contract.test.mjs` 新增三条静态检查：①每个 `NInput` 必须 `value` + `onUpdate:value` 成对；
  ②`settings.mjs` 的 `DEFAULTS` 必须与 `runtime/lib/config.mjs` 的 `DEFAULT_CONFIG` 逐键相等（防两处漂移）；
  ③纵向滚动容器必须显式 `overflow-x: hidden`，且文件里不得出现横向滚动。
- `e2e-temp/dsh-chat-ui-measure.mjs`：把真 `ui.mjs` / `settings.mjs` 塞进宿主真实 Toast 样式与
  `SettingRow` 样式里量（Playwright），夹具全是不可断的长路径/长 JSON；并且**在浏览器里真打字**，
  断言 `plugin.config.set` 收到 `cardTitle: '我的 DSH 小窗'`、越界数值 `99999 → 200`（number 类型）。

## 教训（给下一个插件）

1. 宿主 Toast 的几何是写死的（`.toast-root` 24.5rem → 栈内容 22.5rem），插件卡片只能 `width:100%`。
2. `overflow-y: auto` 不是「只管纵向」；长文本的插件必须显式 `overflow-x: hidden`。
3. Naive 组件用 `value` 就是受控：**给 value 就必须接 `onUpdate:value`**，否则用户会说「改不动」。
4. 改 `runtime/main.mjs`（sidecar）必须重启 sidecar 才生效，只重载卡片不够；
   `ui.mjs`/`settings.mjs` 是 blob 热加载，但样式注入不能「有就跳过」（Toast 窗跨挂载复用同一 document）。
5. 别用 PowerShell `Set-Content` 回写带中文的源文件（本机控制台 GBK 会把 UTF-8 写坏，
   生成不可读文件）；要用能保字节的编辑方式。
